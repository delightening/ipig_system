## 0. 文件版本策略（最重要）

- **產出兩個「單語版」**：中文版（`lang='zh'`）與英文版（`lang='en'`），**不是**官方那種「中英同頁雙語版」。
- 版型與字型以**官方這份 PDF 為準**；每格只顯示一種語言（`L('中','en')` macro 切換）。
- **翻譯不在此範圍**：英文版自由填寫欄位內容暫維持原文，標籤已英文。
- 中文版：題目／說明區**不含英文**（如 §1 研究名稱只顯中文、§8 代碼說明去括號英文）。

## 3. 頁面 / 頁首頁尾

| 項目 | 值 |
|---|---|
| 紙張 / 邊距 | A4 直式；`@page margin: 24mm 12.7mm 26mm 12.7mm`（上 右 下 左）|
| 頁首 | `@top-left` 文件編號 AD-04-01-01F（字距）／`@top-right` 頁 次/ 總頁數 X of Y（頁碼用 `counter()`）|
| 頁尾 | `@bottom-center` 版權中英兩行**粗體**；英文 DrPIG. 後**兩個空格**（base.html）|

**已知限制（CSS @page）**：頁首位於內文上邊距內，且每頁不同頁碼須用 `counter()`（只能放 @page margin box），故**頁首 y 與內文起始 y 受同一上邊距牽動，無法同時 = 官方兩值**。`position:fixed` 可解位置但會破壞每頁頁碼，不採。
- 定版＝**折衷 A**：上邊距 24mm → 頁首 y≈9.8（官方 10.3）、內文表格 y≈32.8（官方 26.5，均勻偏低 ~6mm）。
- 頁首左右同理無法只內縮頁首（會連動內文），維持貼 body 左緣 12.7（官方頁首另內縮 ~3mm 屬 Word 頁首邊距特性）。

## 4. 縮排（階層遞進）

- §N（h2）齊左 0 → 小節 N.N（h3）`padding-left:1.2em` → 子小節 N.N.N（h4）`2.4em`；內容隨所屬層級。
- `h4.subsub + :not(h2):not(h3):not(h4)` 縮 2.4em（**排除標題**，否則連續 h4 或其後 h3 會被多縮一層）。
- `.summary-text` 基礎左縮 1.2em；`.checkbox-row/.grid-*/.pain-list` 基礎 1.2em。

## 5. 分頁（keep-together）

- 內容區塊（`.summary-text/.free-text/table.kv/table.data/.grid-*/.checkbox-row/.pain-list/ref 清單/.hazardous-block`）一律 `break-inside: avoid`：整塊不被分頁切開，**放不下整塊移次頁**；區塊本身超過一整頁時瀏覽器自動允許切。
- 標題 h2/h3/h4 `page-break-after: avoid`（標題不孤兒、緊跟首區塊）→ 達成「小節整塊」。
- **章節內不放強制分頁**（自然流動）；僅 §N（h2）`page-break-before: always` 換頁起。

## 6. 是非題格式 + checkbox 顯示原則

- **標題層級是非題一律 inline-yn（是/否置右）**（`.inline-yn`，h3/h4 皆適用）：
  **3.1.1、4.1.1、4.1.4、2.3.1–3、4.3、4.4、4.6、6.7…**。`<span>題目</span><span class="yn">{{ cb(yes,'是') }}　{{ cb(not yes,'否') }}</span>`，**勾「是」才於下方說明 / 列已選子項**（不勾「是」時下方留白，不顯示 ☐選項清單）。
- **checkbox 原則：只有「是/否」二元題才用 ☑/☐**。
  - **特例 2.2.3「是否為重複他人試驗」**：是/否**左置**二元（`☑是　☐否`，非右置 inline-yn，採 `.checkbox-row`）；勾「是」者於下方 `.sub-checked` 分兩種詳述——(a) `duplicate_status='yes'` ＝「重複他人試驗　重複實驗之必要性：{說明}」；(b) `duplicate_status='continuing'` ＝「本申請人延續性實驗：{說明}　前次核准 IACUC 編號：{編號}」。`status` 為 `no`／`n_a` 皆勾「否」（`n_a` 委託試驗併入否，不另顯註記）。
  - **表格儲存格內仍保留行內 ☑是/☐否**：3.1.2/3.1.3「是否為無菌製備」、§1 GLP/非GLP 配對。
  - **非是否的多選／選項區去掉 ☑/☐，只列「已選項目」純文字**（每項 `<span class="cb-label">` 區塊顯示）：
    4.1.1 麻醉方法（4.1.1 標題本身是 inline-yn，方法清單列於下方）、4.1.3 疼痛分級（**只列已選類別 + 已選項目，隱藏未選類別**）、4.1.5 徵兆、4.1.8 安樂死/處置、6.1 手術種類、計畫類型/種類/經費。
  - **例外 6.3 無菌措施＝全列選項 + ☑/☐**（使用者指定）：手術 checklist 性質，**列出未做項目對無菌稽核有意義**，故 5 項全顯 `{{ cb(field, label) }}`（不只列已選）。
  - **例外 6.8「骨科手術／非骨科手術」置右**：6.8 標題改 `h3.subsection.inline-yn`，骨科/非骨科二選一以 `.yn` 置右（同 6.7 是/否對齊）。
